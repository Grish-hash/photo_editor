PHOTOEDITOR REDESIGN - WEB TECHNOLOGY LAB

Files:
- home.html       Landing page
- index.html      Login / Sign Up DOM events page
- editor.html     Editing services, photo preview, and timing events page
- photo_edit.html jQuery Photo Editing Cost Calculator page
- style.css      Shared styles for all pages
- script.js      Shared DOM, form, image preview, and timing-event JavaScript
- jquery.js      jQuery calculator functionality

HOW TO RUN:
1. Extract this ZIP into a folder.
2. Open the extracted folder in your editor (for example, WebStorm or VS Code).
3. Open home.html in your browser, or use your editor's browser preview/live server.
4. Use the navigation bar to move between all four pages.
5. The jQuery calculator needs an internet connection because jQuery is loaded from the official jQuery CDN in photo_edit.html.

NOTES:
- Login and registration are front-end demonstrations only. They do not authenticate users or save accounts.
- The cost calculator uses sample prices and does not process payments.
- The image preview is local to the browser; it does not upload the image to a server.
- If you have audio.mp3 and sample_vid.mp4, place them beside editor.html to use the tutorial media controls.
